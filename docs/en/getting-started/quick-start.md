# Getting Started

[简体中文](../../zh-CN/getting-started/quick-start.md)

Use this guide to install the InsightOS Semantic Public Preview locally and run the depalletizing simulation example.

## 1. Download

Download the current Public Preview from this repository's **GitHub Releases** page:

- The installer for your platform.
- The depalletizing example asset package.
- The current Release Notes.

See the Release Notes for system, CPU, GPU, browser, and disk requirements.

## 2. Install

Run the installer and place the asset package in the directory specified by the Release Notes. When installation completes, the terminal displays the local Insight Studio URL and login information.

## 3. Open Insight Studio

1. Open the local URL printed by the installer.
2. Sign in with the initial account information in the Release Notes.
3. Find the Depalletizing project in the project library.
4. Open the project and wait for the simulation scene to load.

## 4. Run the Example

Read the Skill documents in the project and enter this request in the conversation panel:

> Move the boxes from Area A to Area B and stack them in three layers.

Insight Studio displays the interpreted goal, generated task flow, and simulation execution.

## 5. Stop or Uninstall

Use the management commands included with the installer to stop, restart, or uninstall InsightOS Semantic. See the current Release Notes for exact commands.
