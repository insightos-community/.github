# Getting Started

[English](../../en/getting-started/quick-start.md)

本指南用于在本地安装 InsightOS Semantic Public Preview，并运行拆码垛仿真示例。

## 1. 下载

从本仓库的 **GitHub Releases** 页面下载当前 Public Preview：

- 对应平台的安装包。
- 拆码垛示例素材包。
- 当前 Release Notes。

具体系统、CPU、GPU、浏览器和磁盘要求以该版本 Release Notes 为准。

## 2. 安装

运行下载的安装包，并按照 Release Notes 将素材文件放到指定目录。安装完成后，终端会显示 Insight Studio 的本地访问地址和登录信息。

## 3. 打开 Insight Studio

1. 在浏览器打开安装程序显示的本地地址。
2. 使用 Release Notes 中提供的初始账户信息登录。
3. 在项目库中找到“拆码垛”项目。
4. 打开项目，等待仿真场景载入。

## 4. 运行示例

查看项目目录中的 Skill 文档，然后在对话框输入：

> 把 A 区的货箱搬到 B 区，码放三层。

Insight Studio 将展示系统理解的目标、生成的任务流程及仿真执行过程。

## 5. 停止或卸载

使用安装包附带的管理命令停止、重新启动或卸载 InsightOS Semantic。具体命令以当前 Release Notes 为准。

下一步可阅读[用户手册](../user-guide/insight-studio-and-projects.md)或查看[Reference / FAQ](../reference/faq.md)。
