## 支持哪些机器人和场景？

InsightOS 面向人形机器人、四足机器人、机械臂和移动机器人等多种本体，支持通过适配器连接不同品牌和型号的机器人。

当前产品围绕以下场景进行开发和验证：

- 售货仓和仓储取货配送。
- 拆码垛搬运。
- 多机协同流水线。
- 定时巡检。

二进制安装器包含原生 MuJoCo、R1 Pro Robot Bundle、场景资产，以及导航、抓取和放置技能。安装流程见[快速开始](../getting-started/quick-start.md)，各组件配套版本见[版本清单](https://github.com/insightos-community/quick-start/blob/main/repo-versions.json)。

## 如何参与项目？

可以通过以下方式参与 InsightOS：

- 在 GitHub Issues 中提交问题和 Feature 建议。
- 通过 Pull Request 改进已经开放的源码和中英文文档。
- 基于 SDK 开发 Skill、Ability 和机器人适配器。
- 共建场景应用、仿真资源和示例项目。

提交贡献前请阅读[贡献指南](../../../CONTRIBUTING.zh-CN.md)。
