# Contributing to InsightOS

[简体中文](./CONTRIBUTING.zh-CN.md)

Contributions to InsightOS are welcome, including code, documentation, examples, and issue reports.

## Issues

Include the InsightOS version, environment, reproduction steps, expected result, and actual result. Search existing Issues before opening a new one.

## Pull Requests

1. Open an Issue first for substantial changes.
2. Keep the change focused and include relevant tests or examples.
3. Update both English and Simplified Chinese documentation for user-visible changes.
4. Do not submit credentials, private data, proprietary code, or content you cannot redistribute.
5. Confirm that your contribution can be published under this repository's license.
